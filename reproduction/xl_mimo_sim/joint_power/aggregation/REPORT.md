# 联合控制第五轮：同样本量状态覆盖消融

2026-09-22。已完成，不存在需要继续等待的训练作业。本报告是研究验证，不是
独立测试或已解决 major revision 的声明；原稿及两份四页 PDF 保留不变。

## 结论

本轮否定了“补足低激活状态就足以建立学习优势”的简单解释。
新状态覆盖组名义场景为 **130.190 J / 1.042%**，比上一轮学习器
134.226 J / 1.637% 有改善，但比强 PRS 的 119.981 J / 0% 仍多耗 **8.51%**。
同样本量、只新增 PRS 状态的对照为 **124.765 J / 2.530%**，反而更省能量。
它们的可靠性也不同，因此既不能说覆盖无用，也不能说覆盖带来了独立的节能优势。

另一个诊断发现：固定较低惩罚权重 1 时，新覆盖组在名义场景可到
104.545 J / 2.143%，相对 PRS 少耗约 12.87%；但高场景两个种子不达标率
为 8.869% / 10.179%，超过 5%。这只是原网格中的**事后诊断点**，不是新选择的
成功控制器，也不是可拿来替换论文摘要的节能结论。

因此，本轮贡献是缩小了故障原因：状态覆盖不是充分修复；所有场景共用一个惩罚权重
会限制能量—可靠性权衡，风险改善的预测误差也仍存在。没有调差搜索或修改原始数据。

## 1. 冻结协议与样本

协议为 `PLAN.md`。新训练流 4109220000 每场景 8 条外生轨迹，共 24 条；
新预测验证流 4209220000 每场景 4 条，共 12 条。每条轨迹分别执行 PRS 和上轮固定
学习策略，形成 72 条行为轨迹，但只有 **36 条独立外生轨迹**，不能把配对行为重复算样本。
旧学习访问策略：偶数轨迹用种子11/价格4，奇数用种子22/价格2，采集前固定。

每条行为轨迹采样 8 个根状态，每个根状态对 17 个候选执行 4 时隙后使用同一因果 PRS
至回合末尾。共 576 个新根状态、9,792 个候选标签。候选分支共享外生信道，但硬件、
CSI 缓存、估计器及恢复倒计时相互隔离；特征不读未来。

两组训练状态数都为 384：共同的 192 个旧 PRS 训练根状态，加上 192 个新 PRS 根状态
或 192 个新学习访问根状态。共同预测验证为 192 个新状态，96 个来自 PRS、96 个来自
学习策略。训练/验证按完整外生轨迹分离，测试数据未参与训练。

| 新增训练根状态 | 低场景 <4 个活动子阵 | 名义场景 <4 | 高场景 <4 |
|---|---:|---:|---:|
| PRS 访问 | 0 / 64 | 0 / 64 | 0 / 64 |
| 学习策略访问 | 45 / 64 | 33 / 64 | 12 / 64 |

覆盖组共新增 90 个低活动数状态；数量对照为 0。最低活动数从 4 扩展到 1。
这验证了一维活动数覆盖变化，不代表整个高维状态空间已经充分覆盖。

## 2. 等预算训练与控制选择

两组相同 AbsoluteValue 网络（两层64单元SiLU）、绝对失败次数目标、能量差目标、
AdamW、每批16个完整根状态、80轮、种子11/22。每组由自身训练数据归一化。
因此架构、数据数量和更新次数相同，但归一化统计不同且不假装完全相同输入分布。
4次训练均按共同预测验证损失选择 epoch20；没有按后续控制输赢重选权重。

在已使用过的控制验证流3909220000上，对每组/种子评价9个价格，共432个新策略回合。
它是参数选择与研究数据，不是新的独立测试。选择规则保持为最坏场景超过5%的程度、
平均能量、最坏场景不达标率。PRS-added种子11/22选价格2/4，覆盖组都选4。
108个同轨迹旧对照回合经散列校验后复用，没有改结果或重新挑轨迹。

## 3. 完整选定策略结果

每格为“能量 J / 用户-时隙速率不达标率 %”，均值包括每场景4条共享轨迹；
学习策略均报告两个训练种子，不删除较差种子。

| 方法 | 低场景 | 名义场景 | 高场景 |
|---|---:|---:|---:|
| PRS-added 学习对照 | 103.706 / 0.952 | 124.765 / 2.530 | 158.390 / 3.780 |
| Visitation-added 覆盖组 | 102.415 / 0.536 | 130.190 / 1.042 | 164.137 / 4.196 |
| 上轮绝对次数学习器 | 99.014 / 1.250 | 134.226 / 1.637 | 163.621 / 3.542 |
| 上轮有符号差值学习器 | 148.542 / 0 | 135.232 / 0.923 | 154.694 / 4.375 |
| 原 PRS＋共同功率控制 | 117.846 / 0 | 119.981 / 0 | 165.013 / 0.714 |
| 选阈值 PRS | 117.846 / 0 | 119.981 / 0 | 165.013 / 0.714 |
| 完整数量搜索 | 83.400 / 3.036 | 93.655 / 9.643 | 126.558 / 19.286 |
| 粗数量搜索 | 89.369 / 3.869 | 103.123 / 5.893 | 138.003 / 11.310 |
| 全子阵＋共同功率控制 | 284.767 / 0 | 285.227 / 0 | 288.520 / 0 |

覆盖组相对旧绝对次数学习器，名义平均节能 3.01%，但能量配对差的描述性95%区间为
[-11.205, 2.069] J，跨零；高场景能量与不达标率均未改善。
相对同样本量学习对照，名义多耗5.424J，区间[-10.812,16.072]J，同样跨零；
平均不达标率减少1.488个百分点。不能只取可靠性改善忽略能量，或反过来。

覆盖组两种子的名义能量为130.748/129.632J，均高于PRS。
最坏场景不达标分别4.107%/4.286%，都满足预设5%点估计筛查，但**能量优势筛查失败**。
没有启用独立开发流4009220000。自助法按训练种子与整条轨迹重采样，仅2种子、
每场景4轨迹且经过选参，区间是描述性不确定性，不是独立确认或选择后显著性检验。

完整/粗搜索在名义和高场景违反5%目标，不能用其最低能量声称可靠最优；
但低场景完整搜索可行且比覆盖组更省，不能省略该不利结果。
这里的粗搜索仍为候选集合对照，不是已证明等计算预算对照，详见`../BUDGET_AUDIT.md`。

名义覆盖组比PRS多出的10.209J，分解为电路/处理+5.748J、功放+1.341J、
切换+3.073J、导频+0.047J。平均活动数量略少于PRS不等于总能耗更低：
恢复中的模块仍耗电，频繁开关也付出额外代价。

## 4. 已有标签上的预测诊断

在共同预测验证的名义64个根状态中，覆盖组按已选价格4选择一次动作再由PRS收尾：

| 种子 | 预测能量差 J | 实际能量差 J | 预测失败用户-时隙差 | 实际差 |
|---|---:|---:|---:|---:|
| 11 | +0.231 | +0.470 | -0.847 | +0.156 |
| 22 | +0.002 | +0.234 | -0.715 | +0.250 |

两个种子仍为没有兑现的预期风险下降付出了能量；56.25%/50.00%的根状态选择中，
出现“预测风险差为负、实际差非负”。这支持继续审查风险目标和决策规则，而不是仅扩大覆盖数据。
这些是单次干预的实现回报，不是精确条件期望；不是全部负风险差必然错误，也不是新的闭环策略成绩。

## 5. 原网格揭示的固定权重限制

不重训、不新增控制评价，重新列出原432个回合的全部价格—场景结果。覆盖组价格1时：

| 场景 | 种子11：J / % | 种子22：J / % |
|---|---:|---:|
| 名义 | 107.144 / 2.679 | 101.947 / 1.607 |
| 高 | 141.962 / 8.869 | 134.469 / 10.179 |

名义均值104.545J / 2.143%，比PRS少耗12.87%，两个种子在该场景均低于5%。
但是相同价格在高场景违反约束，不能据此把失败gate改成成功，也不能只挑名义场景替换正文。
PRS名义不达标率为0，二者也不是严格相同可靠性点，需要报告完整能量—可靠性权衡。

按场景分别事后选价只是放松问题的诊断，不是可部署控制器。部署不能直接读取实验的
隐藏速度/负载标签，再把按标签分配参数描述为自主决策。本轮未实现任何这种场景预知策略。
下一项有依据的检验是**在可观测信息或已用可靠性预算下直接进行受约束能量选择**，
并与相同能力的非学习搜索比较；须先冻结规则，不能在控制验证后任意切换参数直到获胜。
新策略也不能把估计的剩余失败次数当成已校准上界或硬安全保证。

原网格、按场景放松后的诊断和限制说明在`price_diagnosis/`；预测误差在`prediction_audit/`。
这两项都是使用已有数据的事后诊断，未改变冻结模型、选择和正式结果。
