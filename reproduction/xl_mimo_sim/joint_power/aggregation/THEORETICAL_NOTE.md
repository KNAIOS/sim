# 为什么本轮只检验访问状态覆盖

这是解释实验动机的研究笔记，不是已完成的论文定理或投稿结论。

## 固定后续策略的真实动作价值

设 B 为固定预测搜索，g_t 为同一决策区间的能量与速率不达标惩罚：

    g_t = E_t / E_full_slot + lambda * F_t / K.

E_t 为区间总能量，F_t 为失败用户-时隙数，K=3。
在理想的充分 Markov 状态及正确条件期望下，

    Q_t^B(s,a) = E[g_t + V_{t+1}^B(s_{t+1}) | s_t=s, a_t=a],
    A_t^B(s,a) = Q_t^B(s,a) - V_t^B(s).

这里动作执行一个4时隙区间，然后B执行到140时隙末尾。参考动作B(s)的真实优势为零。
若精确选取使Q_t^B最小的动作，固定价格lambda下可得到标准策略改进关系；
已有理论见[Bertsekas原作者讲义](https://web.mit.edu/dimitrib/www/RLTopics_2021_Lect2.pdf)。
这不是新的RL原理。有限样本神经网络和不充分观测不自动满足这些前提。

尤其，优化惩罚和并不保证平均不达标率不超过5%，更不保证每用户每时隙安全。
本项目的可靠性仍必须通过独立控制评价检查，不能由sigmoid或正则项推出。

## 为什么只在搜索经过的状态预测准确还不够

有限时域且终端代价一致时，真实优势满足望远镜求和关系：

    J_pi(s_0) - J_B(s_0)
      = E_pi[ sum_t A_t^B(s_t, pi(s_t)) ].

右侧平均沿的是**学习策略pi访问的状态分布**，不是B访问的分布。
原192个训练根状态活动子阵数均不少于4，因此它们的平均拟合误差，不能限制pi反复进入
低活动数、陈旧CSI和不同恢复状态后的动作价值误差。训练候选包含低数量动作也不够：
动作之后以B收尾的标签，不等于在相应新状态继续执行pi的训练根状态。

若在相关状态和所有动作上有统一Q误差界epsilon，估计Q的贪心动作相对B的单步优势
最多可退化2epsilon。但这里没有这样的统一界或校准证书，只有有限验证误差。
对训练分布的低平均损失，不能擅自代替对pi访问分布的统一误差保证。

这类顺序决策引起的分布变化早有研究。Ross等人的
[AISTATS 2011原论文页面](https://proceedings.mlr.press/v15/ross11a.html)
讨论了当前动作改变未来观测分布的问题。本轮不是该文算法的复现：
这里学习能量/失败次数的rollout回报，而非专家动作标签；只有一轮固定访问策略的数据增加，
没有实现其多轮无遗憾算法或继承相应保证。因此不能把“增加自己访问的状态”单独称为新颖贡献。

## 本轮可以证伪什么

两组均使用同样384个根状态、相同网络、更新次数、训练种子及验证选择规则。
唯一设计性区别是新增根状态来自B还是先前冻结的pi。其后的标签策略均为B。

- 若Visitation-added只降低预测损失，却不改善实际控制，状态覆盖不是充分修复。
- 若两组同时改善且差别很小，不能将改善归因于访问状态机制，可能是样本量或新轨迹。
- 若Visitation-added在相同约束下优于PRS-added，才有有限样本的机制支持；还须独立确认。
- 即使比旧RL好，未超过保留的强搜索，也不能宣称已解决审稿人的R1。

低活动数是已测量的一维覆盖指标，不代表整个343维状态支持集充分重叠。
本轮还会核查真实访问数、能量分项和配对回合差；不把更大的网络、更多试验或更弱搜索
直接当作改进，也不预设新候选必须成功。
