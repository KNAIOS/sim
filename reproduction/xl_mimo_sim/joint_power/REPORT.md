# 联合子阵与发射功率控制：第一阶段实现、验证和差距诊断

日期：2026-09-22。状态：**新分支已实现并完成有界开发验证；候选未通过预先冻结的节能优势筛查，不能替换论文结论。**

## 1. 这次实际做了什么

作者已明确允许联合子阵与发射功率控制，原先缺少研究范围授权的问题已解除。
新代码和数据单独保留，没有改动原实验、原模型代码、既有检查点、四页论文源稿及 PDF。
没有安装依赖、改系统设置或登录服务器，使用项目内 `sim/.venv`；两个训练进程各用一个计算线程。

这不是只对旧曲线做功率后处理：候选动作评价、实际执行能量、训练代价与验证都使用新功率模型。
IEEE 实验技能用于明确共同物理能力、对照、数据划分及停止门槛；没有按结果调低基线性能。

- 外层：每四个时隙选择激活子阵数量及相应排序前缀，另有保持原开关命令的动作。
- 内层：每个时隙根据当前已激活支路的 CSI，求满足各用户速率的最小发射功率；保留用户间干扰。
- 所有新联合策略均允许 1–16 个子阵，总发射功率上限均为 1.2 W。不是只给 RL 去掉原来的 4 子阵下限。
- 旧 PRS 的固定功率/变功率两条对照仍保持 4–16 个子阵，标明不同动作域，用于检查共同功率控制收益。
- 同样的唤醒时延、开关能耗、导频开销、当前活动支路观测和休眠支路陈旧 CSI；没有搜索专属噪声或不可见信息。

### 功率模型

固定单位范数 RZF 波束方向，定义 `G[k,j]=|h[k]w[j]|²`。速率门限对应 SINR 门限 `gamma[k]`，
于是约束为 `p >= Fp+u`，其中 `F[k,j]=gamma[k]G[k,j]/G[k,k]`（非对角），
`u[k]=gamma[k]noise/G[k,k]`。当 `rho(F)<1` 且总功率不超过 1.2 W 时，
`p=(I-F)^(-1)u` 是这些固定波束下的逐分量最小可行功率。

这不等于联合优化波束方向，也不是全局最优多用户波束成形。
目标速率全部不可达时，统一退回保留原等功率可达服务（至多要求速率）的功率解，仍逐用户逐时隙计入不达标。
因此“有功率分配”不等于“保证通信可靠性”。

### RL 实现与限制

采用解析预测代价先验加可学习残差的 Double DQN：每个候选 229 维特征，共 17 个候选；
两层 64 单元 SiLU 网络、18,945 个参数，输出候选长期代价，选择代价最小的动作。
输入包含绝对信道强度、复数用户相关性、活动/命令/唤醒状态、CSI 年龄、业务要求和候选能耗/风险。
最后一层零初始化，未训练网络严格等于独立列出的先验策略。

训练代价为归一化能量加 `8 × 速率不达标比例`，折扣 0.98；它仍是**固定罚系数的软约束训练**，
并没有证明满足严格的可靠性约束。功率由解析内层求解，不是网络直接输出连续功率。
解析先验将后一决策区间的预测代价外推至回合剩余部分，这是近似，不是精确价值函数。

## 2. 验证设计及可复现记录

- 2 个训练种子（11、22），各 120 回合、4,137 次网络更新；每 30 回合验证一次，包含未训练初始检查点。
- 按验证集最差场景的 5% 门限违背程度、再按平均能量选检查点。两个种子均选第 120 回合。
- 训练、选模型用验证、开发评价使用不同种子流；没有混入训练轨迹。
- 开发集每场景 4 条共享环境轨迹，共 12 条独立轨迹。8 种方法，其中 RL 有 2 个训练种子，合计 108 次回放、15,120 个时隙。
- 每回合 140 个 50 ms 时隙，即 7 秒；BS 固定，UE 移动。低/名义/高场景分别为 `(0.5 m/s, 0.85倍负载)`、`(2 m/s, 1倍负载)`、`(3 m/s, 1.15倍负载)`。
- 这只是开发筛查，不是投稿级独立确认。108 次回放不能当作 108 条独立环境轨迹。

协议见 `PLAN.md`；冻结输入散列、配置、检查点与全部原始输出见
`../results/joint_power_20260922_phase1`。

完整搜索是**固定空间排序前缀上的全数量搜索**，不是所有 `2^16` 子阵组合或无限时域的全局最优。
粗搜索预先采用 `{1,4,7,10,13,16}` 加保持动作，预测器与功率解不变。
本实现先生成共同候选特征再取子集，所以这只是候选网格消融，**不能宣称实现了等算力或运行时间节省**。

## 3. 全部场景结果

能量单位 J/7秒；不达标率为全部用户-时隙中未达到需求速率的比例，不是分组误码率或实测丢包率。
RL 是两个选定模型的等权平均。所有方法数值异常回退次数为 0。

| 方法 | 低：能量 / 不达标率 | 名义：能量 / 不达标率 | 高：能量 / 不达标率 |
|---|---:|---:|---:|
| 全激活、固定功率 | 305.65 / 0.00% | 305.65 / 0.00% | 305.65 / 0.89% |
| 全激活、功率控制 | 284.88 / 0.00% | 286.12 / 0.00% | 286.94 / 0.00% |
| 原 PRS、固定功率 | 138.51 / 0.00% | 142.50 / 3.51% | 166.60 / 8.81% |
| 原 PRS、功率控制 | 118.61 / 0.00% | 128.00 / 1.07% | 151.49 / 1.31% |
| 联合完整搜索 | 85.76 / 2.38% | 109.13 / 15.65% | 116.50 / 12.56% |
| 联合粗网格搜索 | 92.62 / 3.15% | 122.02 / 2.56% | 129.69 / 7.68% |
| 未训练代价先验 | 85.95 / 2.02% | 108.70 / 15.36% | 115.14 / 12.98% |
| 联合 RL | 133.72 / 0.03% | 150.27 / 2.35% | 156.82 / 2.47% |

### 可以和不可以得出的结论

1. 联合 RL 相对全激活固定功率在名义场景减少约 **50.84%** 能量，但不达标率从 0 增至 2.35%。
   这只是不同运行方案的实测比较，不是“学习贡献 50.84%”或“通信性能不变”。
2. 功率控制本身有共同收益：原 PRS 从 142.50 J/3.51% 到 128.00 J/1.07%。
   不能把这部分解析功率控制的收益专属于 RL。新分配允许在总功率约束下重新分配给用户，所以也可能改善不达标率。
3. 学习相对未训练先验改善了可靠性，但多耗能量；未证明 Pareto 优越。
4. 完整搜索在名义/高场景严重超过 5% 门限。不能用其最低能量直接断言它全面优于 RL。
5. 名义粗搜索与 RL 的样本平均不达标率均低于 5%，但 RL 多耗 **28.24 J（约 23.14%）**。
   两者 2.35%/2.56% 的小差异不能当作可靠性等效已经获证。
6. 名义原 PRS 加功率控制的能量及不达标率点估计均低于 RL。因而即便忽略不可靠的完整搜索，仍没有 RL 节能优势证据。

名义 RL 两个种子分别为 141.85 J、158.68 J，未删除较差种子。
配对的种子×环境轨迹重抽样给出 RL 减粗搜索能量差的描述性 95% 区间 `[11.29,39.19] J`，
不达标率差 `[-2.56,3.10]` 个百分点；只有两个训练种子和四条名义轨迹，区间不能代替充分独立确认。
全部配对结果保存在 `verified/paired.csv`，方向都是 RL 减对应基线；其中 outage 单位为百分点。

## 4. 差距到底在哪里

### 4.1 能量逐项核算

名义场景 RL 相对联合粗搜索：

| 项目 | RL | 粗搜索 | RL 减粗搜索 |
|---|---:|---:|---:|
| 电路与处理能量 | 138.330 J | 111.024 J | +27.306 J |
| 功放能量 | 6.105 J | 9.075 J | −2.969 J |
| 切换能量 | 4.348 J | 0.905 J | +3.443 J |
| 导频能量 | 1.485 J | 1.021 J | +0.464 J |
| 总能量 | 150.267 J | 122.025 J | +28.242 J |
| 平均活动子阵数 | 4.964 | 3.500 | +1.464 |

因此核心能量差来自活动/唤醒电路与处理，以及切换，而不是 RL 发射功率高。
**在保持本轮硬件轨迹不变的前提下，即使把 RL 功放能量完全置零，仍为 144.16 J，超过粗搜索 122.02 J。**
这是一项条件能量下界诊断，不是在模拟零功率仍能通信，也不意味着重新优化硬件后没有改进空间。

按同一个罚系数计算未折扣回合摘要 `E/E_full + 8×outage`：RL 0.6797、粗搜索 0.6040、原 PRS+功率 0.5045。
它不是训练用的精确折扣 Q 值或独立约束优化结果，但说明差距不只是遗漏了现有罚项；这项摘要也没有显示 RL 优势。

### 4.2 预测误差诊断

额外重放名义场景 16 个已冻结回合、560 个决策区间。只比较动作实际保持的前四时隙，
不把八时隙保持动作预测与中途已换动作的轨迹混比。此分析未调模型或策略。

| 方法 | 区间数 | 预测平均不达标率 | 实际平均不达标率 | 预测零不达标但实际失败的区间 / 预测零的区间 |
|---|---:|---:|---:|---:|
| 联合完整搜索 | 140 | 11.67% | 15.65% | 40 / 106 |
| 联合粗搜索 | 140 | 1.90% | 2.56% | 7 / 132 |
| 联合 RL | 280 | 2.14% | 2.35% | 13 / 269 |

完整搜索并非每次都预测满足约束：找不到预测可行的动作时，其统一规则选择速率缺额较小者；唤醒时延也可能阻止立即恢复服务。
在其命令 1–3 个子阵的 116 个区间中，38 个出现“预测为零不达标、实际有失败”。
小数量、陈旧信道和唤醒过程下的风险估计确有失配，需校准。
但各策略到达的状态不同，这不是“子阵数量导致了全部失败”的随机干预证据；不能拿它当作因果归因或预测概率已经校准。

粗网格不只是“更弱”：它排除了部分脆弱配置，可能偶然带来保守作用。这说明减小搜索能力未必让它更差，
也说明不能通过人为加误差保证 RL 赢。

- 11 项单元测试全部通过：解析功率、耦合干扰、总功率上限、不可行服务回退、固定功率与旧 PHY 一致、
  所有候选的硬件能量回放、隐藏/未来 CSI 不泄漏、网络初始化及目标更新等。
- 独立核查脚本不调用新环境、功率解或用户域增益函数；按保存的开关和功率命令，重建天线域复数 RZF、SINR 和硬件状态。
- 108 回合、15,120 时隙的所有不达标指标一致；最大速率差 `1.194e-11 Mbit/s`，逐槽能量分量最大差为 0，回合能量差不超过 `6.822e-13 J`。

- 32 个冻结输入及 18 个训练/评价输出散列核验通过，包括原四页正文源文件与两份 PDF。
- 独立核算证明这些记录的实现和账目一致，**不证明信道已充分标定、模型完整真实、策略最优或论文可接收**。

## 6. 下一轮应修什么，论文何时可换

本阶段停止扩大确认，不追溯更改通过门槛。新的联合控制授权已经生效，不需要再为同一研究范围询问许可。
第一阶段失败不是整个研究被证明不可能，也不是允许把结果改成成功。

下一轮应针对外层硬件控制：

1. 在训练/校准数据中按 CSI 年龄、命令数量、唤醒状态校准可达速率与短期失败预测。
   校准能力同时给到对应强搜索，避免对照能力不一致；先检验可靠性而非制造能量优势。
2. 改善外层长期价值与可靠性目标的一致性，验证保持动作、恢复过程和长期电路能耗是否学对。
   固定罚系数 8 并不是约束最优的保证；后续任何乘子/网络选择只能在训练/验证中完成。
3. 检查多开子阵及不必要切换能否在不增加失败的前提下减少；不能只追求更低发射功率。
4. 新候选若通过有界筛查，再开展更多种子、新环境轨迹及可靠性匹配比较，然后为新方法重新做敏感性和标准化信道验证。

### 建模参考的边界

[de Souza 等的 XL-MIMO 子阵选择/功率分配研究](https://arxiv.org/abs/2102.11438)
研究的是谱效优化，不是本实现的 RL 节能优势证据。
[Chien 等的功率与负载联合能耗优化](https://arxiv.org/abs/2002.01504)
支持同时计入硬件和发射能量的建模思路，但对象为无小区大规模 MIMO，不能称为本场景复现。
采用联合控制、DQN 或解析功率解本身，不足以直接宣称新颖性。
