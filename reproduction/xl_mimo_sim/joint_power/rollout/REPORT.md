# 联合控制第四轮：长期回报、风险目标与训练状态覆盖审计

2026-09-22。这是开发与验证报告，不是最终独立测试，也不是已解决 major revision 的声明。
检测轴：通信控制；公平对照、统计和可复现性；避免过度声称；实验审查与后续规划。

## 结论先行

联合“学习子阵命令＋共同解析功率分配”已经实现，仍未证明学习方法优于强预测搜索。
本轮最有用的新发现是**训练根状态与实际部署状态不匹配**：192 个训练根状态全部至少开启
4 个子阵，但新学习控制器在低、名义、高场景分别有 70.36%、30.36%、6.07% 的决策发生在
少于 4 个子阵开启的状态。这是可核验的覆盖缺口，不是已经证明的全部退化原因。

名义场景在扩展价格验证后，学习控制器为 134.226 J / 1.637% 不达标，强 PRS 为
119.981 J / 0%。学习控制器仍多耗 11.87%，冻结的优势筛查失败，不能替换正式论文为
“RL 明显优于搜索”。完整搜索、粗搜索、失败种子和旧版本数据全部保留。

未安装依赖、修改主机环境、登录服务器或提交稿件。沿用项目内既有 venv；最多两个采集
进程，每进程 Torch 单线程。原稿及两份四页 PDF 未改动。

## 1. 方法与资料的边界

这里的联合控制不是网络直接输出任意连续功率。网络从 1–16 个排序前缀子阵及保持命令中
选择动作；给定实际可用子阵，所有方法共用同一干扰耦合功率求解器及功率上限。
本轮改进候选是 Monte Carlo 动作价值学习，不应继续按旧版三步 Double DQN 描述。

离线仿真可用未来结果制作训练标签；部署决策只读当前因果观测。固定后续策略的 rollout
是已有策略改进思路，不是本项目的新理论；参见
[Bertsekas 原作者课程资料](https://web.mit.edu/dimitrib/www/RLTopics_2021_Lect2.pdf)。
有限样本、函数逼近和反复选择都会破坏精确策略改进所需条件，本实验不继承单调改进保证。
保守离线策略改进亦有已有工作，例如作者的
[SPIBB 项目介绍](https://www.microsoft.com/en-us/research/project/spibb/)；本项目没有实现
SPIBB，也不借用其特定假设下的安全保证。

## 2. 长期标签：存在机会，但尚未学成可部署优势

冻结协议为 `PLAN.md`。24 条新训练轨迹与 12 条探针验证轨迹分别使用流
3609220000、3709220000；每条沿原 PRS 收集 t=0,16,...,112 的 8 个根状态。
共 288 个状态、4,896 个候选标签。训练与验证分别为 192 / 96 个状态，不是
4,896 个相互独立的随机样本。

每个候选执行 4 时隙，随后用各自因果观测下的 PRS 执行至回合结束；记录前 4、16 和全部
剩余时隙的能量与失败用户-时隙数。全部 288 个参考动作的尾段回报均复现原 PRS 轨迹，
原环境及外生信道没有被分支修改。当前特征在读取未来标签前计算。

名义探针验证中，事后知道完整未来的单次干预，在不增加该尾段失败次数时，平均可少耗
1.416 J（按整条轨迹重抽样的描述性区间约 0.909–2.345 J）。这只说明有限样本中存在
长期动作选择空间，不等于 RL 已节能，不能把重叠尾段的收益相加成整回合节能率。
只看前 4 时隙会误选后续更耗能或更不可靠的动作，高场景尤其明显。

原始文件：`../../results/joint_power_20260922_rollout/` 下的分轨迹 NPZ、合并 NPZ、
`trajectories.csv`、`diagnosis/states.csv`、`diagnosis/summary.csv` 及散列清单。

## 3. 有符号差值模型：预测损失下降不等于控制改进

第一候选使用两层 64 单元 SiLU 网络，预测相对 PRS 的完整尾段能量差与失败数差；
以参考动作相减保证零锚点，Huber 损失，两个训练种子，各 80 轮。

原探针要求“不增加相对 PRS 的失败数”，比论文的平均不达标率不超过 5% 更严格，
两者不能混淆。该探针两个种子都选择 epoch 0，即仍执行 PRS，未启动其闭环开发试验。
预测损失最佳的 epoch 20 并未通过原探针。

诊断发现，种子 11、epoch 20、价格 8 的名义状态，选择动作平均预测减少 0.432 个
失败用户-时隙，实际减少为 0；高场景预测减少 1.065 个，实际反而增加 0.656 个。
这说明所选动作存在风险改善的乐观误差，不是断言负的真实条件期望在数学上不可能。
事后把负风险差裁为零仅做诊断，没有包装成验证通过的新方法。

## 4. 绝对失败次数模型与实际约束筛查

新阶段先冻结 `CONTROL_PLAN.md`，保留上一候选的失败结果。风险头改为
\(\widehat F=N\,\mathrm{sigmoid}(z)\)，其中 \(N=3\times\) 剩余时隙，
再以两个绝对次数之差参与决策；能量仍预测相对 PRS 的差。
风险损失为 \(-F\log q-(N-F)\log(1-q)\)。它在总体风险下针对条件均值，
没有假设相关用户-时隙彼此独立，也不因此获得概率校准或安全保证。

网络规模、种子、80 轮训练和训练/探针验证数据不变；检查点按探针预测损失选择，
两个种子均选择 epoch 20。随后在全新控制验证流 3909220000 的 12 条轨迹上选价格，
按最坏场景超过 5% 的程度、平均能量、最坏场景不达标率依次排序。
PRS、完整/粗搜索的阈值也在同一批验证轨迹上选择，另保留原 PRS。

初始 360 个候选策略回合中，绝对次数模型的名义平均为 141.439 J，比 PRS 多耗
17.88%。两个种子最优价格均在价格网格的下边界 4。
因此事先记录 `PRICE_EXTENSION_PLAN.md`，仅补价格 {0,0.25,0.5,1,2}，
再运行 240 个候选回合；不重训、不改旧结果、不把这批反复选参的数据称为独立测试。
种子 11 仍选 4，种子 22 改选 2，优势筛查仍失败。

### 扩展后完整验证结果

每格为“平均能量 J / 平均用户-时隙速率不达标率 %”。低、名义、高场景是不同的
移动速度/需求组合；学习结果平均两个训练种子，每场景共享 4 条轨迹。

| 方法 | 低场景 | 名义场景 | 高场景 |
|---|---:|---:|---:|
| 全子阵＋功率控制 | 284.767 / 0 | 285.227 / 0 | 288.520 / 0 |
| 原 PRS＋功率控制 | 117.846 / 0 | 119.981 / 0 | 165.013 / 0.714 |
| 验证选阈值 PRS | 117.846 / 0 | 119.981 / 0 | 165.013 / 0.714 |
| 有符号差值模型 | 148.542 / 0 | 135.232 / 0.923 | 154.694 / 4.375 |
| 绝对次数模型 | 99.014 / 1.250 | 134.226 / 1.637 | 163.621 / 3.542 |
| 原始完整数量搜索 | 83.400 / 3.036 | 93.655 / 9.643 | 126.558 / 19.286 |
| 原始粗数量搜索 | 89.369 / 3.869 | 103.123 / 5.893 | 138.003 / 11.310 |

不能把完整/粗搜索在名义或高场景违反 5% 约束时的低能量视为可靠最优方案。
同样不能只取学习方法低场景相对 PRS 的 15.98% 节能，忽略完整搜索在该场景也可行且
更省能量，以及名义场景仍退化。高场景绝对次数模型相对 PRS 仅少耗约 0.84%，但失败率更高。

名义绝对次数模型多出的 14.244 J，可分解为电路/处理 +11.620 J、功放 +0.842 J、
切换 +1.580 J、导频 +0.202 J。当前差距主要不是功率求解器少省了电，而是激活、恢复和
保持策略的累计成本。该能耗分解可核算，不应凭分解直接断言哪个训练缺陷是唯一原因。

完整数据在 `../../results/joint_power_20260922_rollout_absolute/`，初始结果在
`validation`，事后明确登记的扩展在 `price_extension`。两个阶段的 gate 均为 false。
未启用新开发流 4009220000；原探针准备的 3809220000 也未启用。

## 5. 根状态覆盖缺口

训练候选虽然包含关闭到 1、2、3 个子阵的动作，但根状态始终来自 PRS。
“从至少 4 个子阵出发执行一次低数量动作的标签”，不等于“在已经长时间只开少量子阵、
CSI 陈旧且唤醒正在进行的状态下继续决策”的训练经历。

从冻结特征提取 hold 动作之前的活动状态：192 个训练根状态的活动数范围为 [4,16]。
重放两个种子的 24 个已选验证回合，在每个 4 时隙决策点读取当前活动数：

| 场景 | 决策点数 | 当前活动数小于训练最小值的比例 |
|---|---:|---:|
| 低 | 280 | 70.36% |
| 名义 | 280 | 30.36% |
| 高 | 280 | 6.07% |

此项事后诊断支持增加策略实际访问状态的训练覆盖；它尚不能证明补样本一定节能，
也不能代替对陈旧 CSI、准备倒计时和动作价值误差的进一步验证。
原始状态表及审计为 `coverage_audit/states.csv` 和 `coverage_audit/report.json`。

## 6. 正确性、预算与主张—证据账本

已有 45 项单元测试通过；物理重放逐槽独立构造天线域 RZF、SINR、功率、硬件倒计时与
全部能量分项。初始 108 个选定回合共 15,120 时隙的最大速率差为 7.66e-11 Mbit/s，
能量分项误差为零。扩展后重放绝对次数模型 24 回合/3,360 时隙，最大速率差
5.06e-12 Mbit/s，能量误差为零；其余 84 个选定回合与先前已核验结果相同。
这些核验支持数值实现正确，不代表模型已经实测标定、方法新颖或论文可以接收。

本轮控制评价里的粗搜索沿用先算全候选、再筛步长的原实现，只是候选集对照，不能称为
真实低计算预算。真正先筛后算的实现及计时在 `../BUDGET_AUDIT.md`；该审计还表明
目前学习模型有完整候选特征成本，并没有“RL 更快”的证据。不能在看到输赢后给搜索加噪声。

| 主张 | 所需证据 | 本轮现有证据 | 缺口及风险 |
|---|---|---|---|
| 长期决策有节能机会 | 当前信息可识别、可执行的改进 | 单次事后最优干预有空间 | 非因果诊断不是部署成绩；Major |
| 新风险目标改善控制 | 同条件配对闭环对比 | 不同场景得失不一 | 未建立稳定模块优势；Major |
| 训练状态覆盖不足 | 冻结训练状态与实际访问状态对照 | 已量化低活动数覆盖缺口 | 因果修复效果未验证；Major |
| RL 超过强搜索、解决 R1 | 相近可靠性下独立配对验证 | 优势筛查失败 | R1 仍 open；Critical |
| 新方法满足 R2/R3 | 新方法的敏感性与标准信道控制实验 | 本轮尚无 | 不能沿用旧算法证据；Major |
| 全文 major revision 完成 | 科学证据、四页稿、标黄稿及回复一致 | 旧文件保留 | 未完成，不提交 |

## 7. 下一项最小研究动作

停止扩大本失败候选的确认试验。下一阶段应先冻结新协议，用**全新训练轨迹**同时收集
固定学习策略与 PRS 实际访问的根状态，针对这些状态生成相同的全动作、共同后续策略标签。
增加“新增 PRS 状态、相同样本量”的对照以区分纯样本量和覆盖变化；保持物理参数、
功率分配、强搜索、训练种子及约束一致。验证和测试轨迹不得混入训练。

这是一项有界的状态分布修复检验，不是承诺优势，也不是靠持续更换验证集直到获胜。
只有预先规定的控制筛查通过，再做独立确认以及新方法的 R2/R3，并同步四页正文、
黄色标注稿和逐条回复。当前不存在联合控制授权缺失，完整目标尚未完成。
