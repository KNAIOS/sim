# 同动作域PRS补强：撤销对七基线筛查的充分性解释

2026-09-22。两个新增基线48回合/6,720时隙完成，全部原408回合和原始结果保持不变。
这是同一独立确认数据上的事后基线补充，不是另一批独立测试，也没有重新选择主方案。

## 核心发现

当前学习候选与Raw完整数量搜索允许1–16个子阵，原PRS却从4个起搜。仅仅提供一个
同数量域Raw搜索，不足以排除“把PRS原有搜索规则扩展到1–16”更强的可能性。
因此新增Expanded PRS与Expanded budgetPRS；只改候选数量域，其他预测、排序、
RZF、门限/预算系数、失败回退及实际解析功率求解保持一致。没有调参或加噪声。

| 方法 | 低场景：J / % | 名义场景：J / % | 高场景：J / % |
|---|---:|---:|---:|
| 学习主候选 | 90.959 / 1.443 | 100.746 / 3.274 | 129.850 / 3.289 |
| Expanded PRS | 84.603 / 1.875 | 94.833 / 3.571 | 130.790 / 2.827 |
| Expanded budgetPRS | 84.574 / 2.619 | 94.094 / 4.405 | 128.732 / 4.107 |

两增强PRS均在全部场景均值满足5%。主候选名义比最强可行纯参考多耗7.07%，
两个种子的101.464/100.028J也都高于94.094J，原>=2%节能/不退化的主判据不再成立。
其不达标率更低，不是“搜索两项必然全面支配”，但也不是学习更节能。

七基线报告中相对原PRS的16.04%仍是正确算术，却不能排除可选数量域变化这一因素，
所以不能写成强化学习净贡献或审稿R1已解决。实际不是把原数据改坏，而是加入此前
缺少的更强对照后，之前的解释不充分。旧gate.json保留，最新判断单独存放在
expanded_comparison/gate.json，passed=false。

## 相同风险再次核对

将这两种PRS加入七种原基线，重新枚举九控制器的经验双策略混合。仍是事后拟合
概率的期望分析，不是实际随机部署或任意策略的全局最优。

|---|---:|---:|---:|

名义混合为8.333%的原预算PRS加91.667%的Expanded PRS，经验不达标率与学习同为

跨零，既不证明总体更差，也不支持显著更优。低/高微小有利均值区间同样跨零。
在完整5%风险额度下，三场景经验混合能量83.672/92.966/126.576J也均低于主候选。

## 对下一轮和论文的实际影响

1. 基准回退仍确实修复了部分高开销决策，属于有效工程诊断；但它未解决同域强基线
   下的学习优势，不能继续把16%写进摘要作为学习贡献。
2. 长期能量头的必要性本来就没有得到消融支持，不能用修饰语言补成新颖性。
3. 原价值训练和完整尾段标签的后续策略仍是最少4子阵PRS，强参考现在可到1子阵。
   若继续参考策略价值学习，首先要量化相对这个强参考的真实改进空间和可预测性，
   而不是继续复用弱参考的收益标签或任意给搜索降级。此分析尚未执行，不声称重训有效。
4. 未经新的R1证据，不能把新方法敏感性/标准信道数据仅作为数量补充来宣称完成返修；
   旧稿R2/R3结果也不能证明这版联合控制。完整目标仍active，不标complete/blocked。
