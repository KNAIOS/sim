# 联合控制第二轮：共享风险校准、三步价值学习及唤醒行为复核

日期：2026-09-22。本轮是**实质进展**：实现新候选、完成校准和两个种子的训练、独立评价及物理核算。
**完整 major revision 尚未完成，R1 仍未解决；不把对较弱对照的优势替换成论文的普遍节能结论。**

## 1. 改了什么，哪些保持不变

本轮按 IEEE 实验技能进行通信控制的基线/消融/统计/可复现路由。
研究仍为固定 BS、移动 UE、联合子阵激活与发射功率控制；使用上一轮已独立核算的物理环境。
所有方法的功率上限、速率要求、唤醒时延、开关能耗、导频及 CSI 权限未改变。
继续保留原预测搜索加功率控制、未校准完整/粗搜索和全激活对照。

新尝试分为两个明确保留的阶段：

1. 高维神经校准器：训练后验证误差变差，最优验证检查点仍是未训练模型，**未通过门槛，停止该候选**。
   记录在 `../../results/joint_power_20260922_phase2`，没有覆盖失败或在该候选上继续训练 RL。
2. 低参数分组校准：按预测不达标比例、命令子阵数量、是否唤醒分组，以训练组均值作收缩估计；
   功率与即时能量仍用原解析公式。通过独立轨迹的开发筛查后，把同一冻结预测器同时提供给搜索与 RL。

RL 的关键变化是：删除“某候选动作的后一段代价重复至回合末尾”的动作依赖长期先验。
新 Q 值由校准即时代价、**不依赖候选动作的状态价值项**以及居中的学习优势项构成；用三决策步回报训练 Double DQN。
这避免初始排序被固定保持动作的长期假设支配，但没有从理论上保证更优或约束可行。

价格输入取 `{1,2,4,8}`，回放保存能耗和不达标分量，训练时按采样价格重算代价。
每个种子在验证集上选一个固定的检查点与价格，并非在测试场景里分别调参数。
两个价值/优势分支均为两层64单元SiLU，策略网络37,314个参数，校准表没有可训练在线参数。
原版与新版本还存在探索策略、训练量等差别，因此这不是单独证明某一个模块因果贡献的消融。

协议：`PLAN.md`、`HISTOGRAM_PLAN.md`。原四页稿、原始实验和既有检查点未修改。
没有安装包、改系统设置或连接服务器；全部使用项目内既有 venv，两个训练进程各用一线程。

## 2. 校准效果：有有限改善，没有校准保证

训练使用48条轨迹的28,560个四时隙候选分支。后续真实信道只用于离线仿真标签，控制特征在分支前计算。
分支隔离、隐藏/未来 CSI 不泄漏均有测试。不同候选和同一轨迹内时隙不是独立样本。

神经模型原验证集12条轨迹：未训练时预测平方误差0.005197，训练10回合后0.008580，40回合后0.009593，
未采用训练后模型。此项是验证退化观察；不能据此证明所有神经校准方式都无效。

分组模型使用另一批12条新验证轨迹（7,140个分支），三种收缩强度 `{32,128,512}` 中按验证分数选128：

| 指标 | 原解析预测 | 简单截断预测 | 分组校准 |
|---|---:|---:|---:|
| 不达标比例预测平方误差 | 0.011419 | 0.011204 | 0.009867 |
| 交叉熵 | 0.354609 | 0.190818 | 0.185222 |
| 平均预测减实际风险 | −0.55个百分点 | +0.27个百分点 | −0.98个百分点 |

相对原预测，平方误差点估计降低13.6%，但按完整轨迹分组的重抽样差值区间为
`[-0.003652, 0.000244]`，跨过零，且这是用于选模型的验证集。
**不能称为已证实的统计显著改进、所有条件下可靠的概率，或普适校准保证。**
平均偏差还比原预测更大；某些组只有少量样本。共享校准只是候选模型的有限改进。

## 3. 训练与独立开发评价

- 两个种子11/22，各160回合、11,070次更新；每40回合在12条控制验证轨迹上评价四种价格。
- 种子11选第40回合、价格2；种子22选第160回合、价格8。保留所有历史分数、初始/选中/最后检查点。
- 校准完整/粗搜索分别在同一控制验证集上从 `{0,.02,.05,.10}` 选门限；两者均选0，即无预测可行动作时走最小预测风险回退。
- 独立开发集另有12条环境轨迹，三个预定场景各4条。9种方法，RL有两个训练种子，共120回合、16,800个时隙。

### 哪些优势不能偷换

新 RL 在名义场景比校准四时隙完整数量搜索少用21.27%能量，但该搜索平均开启8个子阵，较保守；
不能只留下它而删掉原PRS。与原PRS相比，RL平均多用14.93 J，即12.17%，不达标率点估计略低。
配对种子×轨迹重抽样的能量差区间 `[-1.65,37.44] J`，不支持稳定节能优势。

高场景平均少用1.40 J（约0.87%），但不达标率从0.77%升至3.42%，能量差区间
`[-22.87,17.56] J`；种子11自身不达标率5.30%，超过门限，不能称为服务保持的稳定优势。
种子22高场景能量162.12 J，仍高于原PRS161.41 J；不能删去种子11后宣称整体获胜。

名义种子11为151.10 J，种子22为124.12 J，训练稳定性尚不足。
相比未训练即时代价策略，RL主要改善高负载可靠性，同时增加能量；这不是能耗和可靠性的全面支配。

因此原冻结筛查为 **passed=false**。没有改门槛、只保留有利场景或混入训练轨迹。

## 4. 搜索门限与时间范围的补充审计

在读取开发结果后，发现校准搜索门限0导致过度保守，启动了明确标注为事后的网格诊断，
协议见 `THRESHOLD_AUDIT_PLAN.md`。没有改变此前的筛查及对照记录。

从冻结校准表而非开发结果导出原 `[0,.1]` 范围内全部可行性变化点，加上原端点，共12个门限。
分别在原控制验证集选择完整/粗搜索的门限，**选完后才**重放开发轨迹。
选中的门限仍是0；288次验证回放和24次开发回放没有改变原结论。
对应3,360个开发时隙的开关、速率、功率、能量均逐项匹配原来已经独立物理核算的记录。

所以在当前校准模型和选择准则下，稀疏网格不是保守结果的唯一原因；不能说加密门限已解决预测限制。
更重要的是，新校准搜索只看前四时隙，而唤醒需要四时隙：它不能充分评价恢复后效益。
`BASELINE_COVERAGE.md` 在开发结果前已经记录：真正宣称R1解决前，仍须有八时隙或更长的校准/稳健搜索对照。
“完整”仅指遍历数量域，不是长时域全局最优；本轮没有等算力、推理时延或实际计算电能的实测声明。

## 5. 新的具体问题：大量唤醒没有进入数据传输时隙

根据已保存命令逐槽重建每次唤醒的生命周期，末尾未完成的唤醒单独列为截尾，不计作失败。

| 名义场景，每回合均值 | 原PRS＋功率 | 新RL |
|---|---:|---:|
| 唤醒次数 | 5.25 | 37.125 |
| 未用于任何数据时隙就再次关闭 | 0.25 | 18.625 |
| 至少进入一个数据传输时隙 | 5.00 | 17.50 |
| 回合终止时尚未分类 | 0 | 1.00 |

这些再次关闭的模块可能刚好在决策前提供了新的CSI，故不能直接称为“完全无用”或把其能量全部算成可消除遗憾。
但这揭示了明确的物理行为问题：学习策略频繁付出恢复与切换成本，却未持续利用新准备好的模块传输数据。

名义 RL 减原PRS的14.93 J能量差分解为：

| 分量 | 差值 |
|---|---:|
| 电路与处理 | +12.161 J |
| 功放 | −0.893 J |
| 开关切换 | +3.501 J |
| 导频 | +0.162 J |

这是账目分解和行为计数，不是已经证明了某个网络缺陷的因果贡献。
从源码看，候选动作特征主要给出数量、开关总数和预测代价，**没有显式编码该候选执行后每一个模块的活动/倒计时/目标位置**。
公共上下文虽有当前硬件位置，网络仍需隐式推断候选之后的空间准备状态。
这构成下一步检验后动作状态表示与延迟收益学习的理由，尚不是“加上就一定更好”的结论。
