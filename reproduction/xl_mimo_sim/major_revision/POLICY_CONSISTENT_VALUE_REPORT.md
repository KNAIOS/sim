# 后续策略一致的价值学习：出现小幅同风险收益，但尚未通过筛查

2026-09-21。作者研发报告；不是投稿结论。执行前方案为
`POLICY_CONSISTENT_VALUE_PLAN.md`。主检验场景预先固定为名义场景。
**八个模型与全部1440条验证记录已完成，晋级判断仍为false。**

## 1. 这次真正改了什么

原标签回答“这次切换后，让搜索mu继续控制，结果如何”。原部署却让
学习器pi一直控制，两者后续动作和通信恢复能力可能不同。因此新增
一次近似策略改进：在搜索状态和学习器自身状态上，分别计算“之后由mu
控制”和“之后由冻结旧pi控制”的真实物理回放代价，然后更新价值网络。

这是对学习目标和采样分布的修正，不是换个算法名字、调大惩罚参数或
改变功率模型。不是新提出的通用RL理论，也不是完整复现某篇算法的保证。
[Ross和Bagnell的原论文](https://arxiv.org/abs/1406.5979)已区分专家后续
代价与学习策略后续代价，并指出前者可能过于乐观；本实验没有取得其
no-regret理论所需的条件。旧235维动作模仿实验没有被重启。

| 实验简称 | 更新时使用哪些状态 | 标签的后续控制者 | 验证什么 |
|---|---|---|---|
| mu_mu | 搜索走过的状态 | 搜索 | 仅追加拟合的对照 |
| mix_mu | 搜索与旧学习器各一半 | 搜索 | 只改变状态覆盖 |
| mu_pi | 搜索走过的状态 | 冻结旧学习器 | 只改变后续代价目标 |
| mix_pi | 搜索与旧学习器各一半 | 冻结旧学习器 | 本轮预指定的新候选 |

保持1500维因果输入、32324参数、16种前缀数量动作、lambda=2和16时隙
评价长度不变。每种子所有版本从相同旧权重开始；每版固定100epoch、
300次更新、19200次根状态呈现，两个种子共八版，不选训练终点。
mu-only每epoch对96个根状态各使用两次，混合版使用192个根状态各一次。
这是同更新预算、不同独特状态覆盖，不能说训练数据条数完全一样。

新训练流108共12条外生轨迹，种子间共享；每种子192根状态、6144个
反事实分支，合计12288分支。旧模型的训练数据只通过初始化和损失尺度
保留；不把旧mu标签错误地混入pi后续目标。12条是新增数据，不是整个
预训练过程的总训练轨迹数。

## 2. 目标不一致确实存在，但并非总是低估风险

相同根状态、相同第一次动作、相同未来下，两个后续策略的C4标签完全
一致，C16则不同。下面在学习器自己走过的状态上，固定第一次动作为
旧学习器选择，列出后续pi减mu的不达标代价差：

| 场景 | 种子11 | 种子22 |
|---|---:|---:|
| 低 | -0.05427 | -0.03722 |
| 名义 | +0.07108 | -0.02261 |
| 高 | +0.10630 | +0.09664 |

每格来自4条轨迹中的32个相关根状态，数值是四个成本块的折扣和差，
**不是不达标率的百分点差**。高场景两个种子都支持“mu后续标签比旧pi
实际后续更乐观”；名义场景方向不一致，低场景旧pi反而更保守。不能
将标签不一致写成所有场景、所有失败的唯一原因。

自身状态也不同，例如高场景搜索根状态平均有7.94个活动子阵，而两个
学习器分别为6.16和7.25。根状态采样在4槽决策边界，恢复延迟也为4槽，
因此本批根状态的恢复计数均为0；这不表示决策块内部不存在唤醒延迟。

## 3. 新闭环结果：名义场景有改善线索，高场景依旧失败

109流与训练流分离，全部拟合完成后才生成。三个场景各8条轨迹，共24条。
所有回合140个50-ms时隙，即7秒；能量含运行、切换和导频。四种强搜索
各12配置，另有mu/full，共1200记录；学习版本含旧模型共240记录。
搜索得到更多验证调参机会，属于对学习候选保守的筛查，不是等调参预算
的算法普遍排名。搜索与学习共享信息权限、动作域和物理模型。

表中学习数据平均两个种子，搜索不复制成两个独立种子；单位为
“整回合能量J / 用户时隙需求不达标比例”。

| 方法 | 低场景 | 名义场景 | 高场景 |
|---|---:|---:|---:|
| mu_mu | 107.99 / 1.16% | 123.86 / 4.93% | 159.51 / 20.79% |
| mix_mu | 110.47 / 0.58% | 124.09 / 4.26% | 163.38 / 18.88% |
| mu_pi | 110.10 / 1.06% | 126.52 / 3.82% | 172.01 / 16.59% |
| **mix_pi新候选** | **112.58 / 0.36%** | **122.31 / 3.72%** | **163.01 / 20.42%** |
| 冻结旧学习器 | 110.87 / 0.49% | 125.73 / 3.66% | 167.79 / 15.76% |
| 最强可行纯搜索 | 100.07 / 3.45% | 125.29 / 3.30% | 205.23 / 4.97% |
| 全阵列 | 305.65 / 0.00% | 305.65 / 0.00% | 305.65 / 2.05% |

低场景新候选用较多能量换取较低不达标；高场景的省电伴随18.13%--22.71%
不达标，不能宣传为可靠节能。不同数据流的绝对能量不得直接相减表示进步。

名义新候选分种子为121.7998J/3.7798%和122.8116J/3.6607%。相对同一
纯搜索125.2941J/3.3036%，少耗约2.79%和1.98%，不达标分别增加0.4762
和0.3571个百分点。因此还必须检查相同风险，而不只比较纯配置。

## 4. 相同风险下的收益约1.1%--1.6%，稳定性仍不足

在四搜索各12配置加全阵列构成的49点有限集合上，枚举不看回合未来的
回合级两策略混合。给定本验证集估计的平均风险，求最低期望能量。
名义最优混合为PRS(min=1,margin=1.08)与PRS(min=1,margin=1.04)，
前者概率分别0.78667、0.84。它是可实现策略类的验证拟合期望，不是
独立实测的随机混合部署，也不是全部可能控制器的最优下界。

| 名义种子 | 新候选能量 | 同风险搜索混合期望 | 能量降低 | 配对能量差均值±样本SD | 8条中能量更低 |
|---|---:|---:|---:|---:|---:|
| 11 | 121.800J | 123.820J | 1.63% | -2.020 ± 9.935J | 3条 |
| 22 | 122.812J | 124.189J | 1.11% | -1.377 ± 9.841J | 3条 |

这是两个种子同方向的小幅样本均值改善，应如实保留；但轨迹差异明显，
只有8条轨迹，且混合参数在本验证集选择，不能称为统计显著或稳定优势。
±后是轨迹配对差的样本标准差，不是置信区间或测量误差。不能缩小误差棒
来美化，也不能只报改善百分比省略不确定性。

低场景在同一0.3571%平均风险下，种子11比混合搜索少3.84J、种子22反而
多4.06J。高场景风险本身不达标；即使强行匹配该高风险，种子11仍多8.13J，
种子22只少0.13J。全场景信息均保留，没有只选名义有利点作为最终结论。

## 5. 为什么仍不晋级

1. 两个名义同风险收益都未达到预先设定的2%研究筛查门槛。**2%不是会议
   的硬性发表要求，也不表示1%的真实稳定收益没有价值**；本轮不能事后
   改门槛并宣布成功。当前小样本离散程度本身也不足以建立稳定性。
2. 两个消融同时存在一致贡献的证据不够。种子11相对mu_pi虽更省电，
   不达标从3.0952%增至3.7798%，超过预设0.5个百分点容差；种子22相对
   旧学习器由2.5893%增至3.6607%，同样超出。把两个种子平均后接近的
   风险写成每个训练结果均不退化，会掩盖这点。
3. 新旧学习策略高场景仍明显违反5%上限。只修正后续目标和训练状态覆盖，
   未成为完整解决方案；不能把高场景节能放进摘要作为有效节能。

按冻结方案停止该候选，不再增加本轮迭代、价格或终点选择，也没有启动
独立确认。仅凭训练拟合误差下降，不能推翻闭环门槛或声称消融成立。

| 返修主张 | 本轮证据 | 当前结论 |
|---|---|---|
| 后续代价目标与实际学习控制不完全匹配 | 配对分支标签和精确回放 | 有限仿真中成立，方向随场景/种子变化 |
| 两项学习修正提高可靠节能 | 四组等更新预算、两个种子、完整闭环 | 名义小幅同风险线索，但未通过完整筛查 |
| R1已经解决，可以替换正文 | 无独立确认，消融和高场景仍不足 | 不能宣称；原稿暂不替换 |
| R2/R3可以沿用证明新方法 | 原敏感性/标准信道证据仅来自原稿模型 | 不能移植；若新方法最终确认需另做 |
