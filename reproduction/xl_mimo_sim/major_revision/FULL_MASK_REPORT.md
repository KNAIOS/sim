# 全数量域的空间动作审计：扩大选择仍未给出稳定节能证据

2026-09-21。按事前冻结的`FULL_MASK_PLAN.md`执行。没有新模型训练，
不替换主稿结果，不重开旧候选门槛。

## 结论

当前固定排序确实遗漏部分可选组合，但在这批预设状态中，扩大到所有
65535种非空组合仍有18/24次选回原动作。其余6次真实回放均少耗电，
其中3次未增加不达标，3次以增加不达标为代价。

**不能据此证明“只扩大动作空间，RL就会更省电”。** 这不是新学习器，
也不是全程运行的空间策略；只有6条已查看过的外生轨迹。R1仍开放。
本轮不启动空间RL训练，也不把局部收益累加为整篇论文的节能率。

## 为什么不是重复早先的位置交换实验

早先`SPATIAL_ACTION_REPORT.md`只在4--16数量域、原PRS延续规则和另一
预测选择准则下检查保留/单次交换。后续已确认物理模型允许1--16个
子阵，本轮因此直接检验完整数量域和全部空间组合，不再局限于交换
一个位置。旧报告和物理模型均未修改。

选择子阵以提高XL-MIMO能效本身已有研究，例如
[Marinello等](https://arxiv.org/abs/2009.02542)；不完整CSI下的跟踪与
风险感知天线选择也已有[He等的TWC工作](https://ieeexplore.ieee.org/document/10478288/)。
本轮枚举不是这些算法的复现，也不构成新的RL创新。

## 实际检查范围

使用已查看的113验证流，每场景最前2条，共6条轨迹，固定时刻0、32、
64、96，共24个相关根状态。基准是最低数量1的原成本搜索，三个场景
裕量固定为1.00/1.08/1.04。高场景不继承此前最佳纯搜索的下限4，
以确保本轮比较共同开放1--16；因此不能把此基准叫作所有已校准策略
中最强的一个。

每个根用当时的CSI估计、预测、实际硬件就绪状态和预测需求，计算所有
非空掩码保持8槽的预测能耗、速率不达标和缺额，共1572840个候选计算。
这个大数字不是独立实验样本量。选动作时没有读取未来真实信道。

在同一张候选表中分别选择：

- 单次交换：数量不变，最多一进一出，原动作也在集合内。
- 同数量任意位置：数量不变，允许任意组合。
- 全组合：数量与位置都可以变。

所有规则共用“先满足预测5%要求，再最小能量；无可行解则最小缺额”
准则，完全相同的预测代价才优先保留原动作。每个选定动作分别做两种
实际回放：保持8槽；或只干预首4槽，随后恢复同一个成本搜索到回合末。
下面是后一种单次干预的结果，不是持续使用新规则的结果。

## 全部预设状态的结果

能量差=替代动作分支−原动作分支，负号表示省电。不达标差是完整140槽
回合平均用户-时隙速率失败比例之差，单位百分点，正号表示更差。
每行都包含8个根状态，包括未改变动作的零差值；每行仅来自2条轨迹。

| 场景 | 规则 | 改变动作/8 | 其中省电且未增不达标 | 平均能量差/J | 平均不达标差/百分点 |
|---|---|---:|---:|---:|---:|
| 低 | 单次交换 | 0 | 0 | 0 | 0 |
| 低 | 同数量任意位置 | 0 | 0 | 0 | 0 |
| 低 | 全组合 | 0 | 0 | 0 | 0 |
| 名义 | 单次交换 | 2 | 0 | -0.3385 | +0.4167 |
| 名义 | 同数量任意位置 | 2 | 0 | -0.2671 | +0.2679 |
| 名义 | 全组合 | 3 | 1 | -0.4194 | -0.0298 |
| 高 | 单次交换 | 2 | 1 | +0.2339 | +0.2976 |
| 高 | 同数量任意位置 | 2 | 1 | +0.1484 | +0.2381 |
| 高 | 全组合 | 3 | 2 | -0.5647 | +0.2976 |

名义全组合的平均能量和失败比例均下降，是应保留的正面线索；但来自
同两条轨迹的相关干预，不能声称统计显著或普遍支配基准。高场景平均
少耗电却增加不达标，不是满足同可靠性条件的节能结论。

## 六次变化逐项列出，避免只展示有利分支

| 场景/轨迹/时隙 | 数量变化 | 能量差/J | 不达标差/百分点 |
|---|---|---:|---:|
| 名义/0/64 | 3→2 | -0.2294 | -2.3810 |
| 名义/0/96 | 6→2 | -2.2731 | +0.2381 |
| 名义/1/64 | 3→2 | -0.8529 | +1.9048 |
| 高/0/64 | 3→1 | -2.4702 | +2.6190 |
| 高/1/64 | 7→5 | -0.7403 | -0.2381 |
| 高/1/96 | 5→5 | -1.3075 | 0.0000 |

因此，最明显的2.47J省电分支反而损失2.62个百分点，不能拿它作为可靠
节能亮点。同数量的最后一行确有局部正收益，也不能据此宣布空间RL有效。

6次变化中有3次原数量不足4，说明旧实验确实没有覆盖当前动作域。
4次新掩码是原掩码的子集，另外2次还改变成员：

- 名义/0/64保持同一条已醒子阵，新增唤醒由2减为1；后续回放有利。
  此根预测不达标仍为1/3，本身并不是预测可行状态，不能包装为安全保证。
- 名义/0/96、高/0/64、名义/1/64减少已醒支路，各有通信损失。
- 高/1/64保持1个已醒支路，新增唤醒由6减为4，并改变部分位置；
  本根预测失败仍为1/6。其回放改善不意味着满足5%瞬时预测门槛。
- 高/1/96由5个已醒支路改为4个已醒加1个新唤醒，整段少耗1.3075J，
  本条轨迹的失败比例不变。这是少量长期硬件/观测耦合机会之一。

这些描述可由保存的掩码、active和countdown逐位核查。不同根的回放共享
未来并改变后续观测，收益不能相加，也不能乘以每回合35次决策。

## 可以和不可以推出什么

1. 固定排序不是全部空间选择；完整域确有个别遗漏，这一点成立。
2. 在本预测器、准则及这些根状态下，18次原前缀已达到全组合的最优
   预测主键，并按声明的平局规则保留。不是18次真实长期最优，也不代表
   原排序在所有状态都最优。
3. 同数量任意组合没有显示稳定的平均收益；数量和位置联合改变只提供
   有限正面线索。不能直接推断扩大网络或动作个数即可修复R1。
4. 可行性数量没有因全组合而增加：低/名义/高均为8/7/6个预测可行根。
   无可行预测不等于物理不可能；预测失败比例也不是校准风险概率。
5. 后续若研究空间学习，必须先解决如何从当前信息选择有利分支，并保留
   同动作集合的强非学习控制。不能用弱化基线或事后挑分支制造优势。
