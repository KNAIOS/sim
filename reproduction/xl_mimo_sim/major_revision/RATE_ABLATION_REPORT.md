# 候选速率输入对照结果（2026-09-20）

## 对照条件

在固定惩罚 4 的 139 维增强 DQN 基础上，增加 13 个候选子阵数量 ×
3 个用户的估计速率/需求比，状态变为 178 维。估计只使用当前或过去
已经观测的复信道，不访问未来真实 CSI，睡眠分支的估计可能过时。
每次决策增加 13 次 RZF 速率求解；网络输入参数数目也增加。

两个种子各 100 轮、相同训练/验证/开发轨迹、相同优化器、奖励和模型
选择规则。与已完成的固定惩罚实验比较，不改其数据或物理参数。
开发集此前已看过，因此不是新的盲测。不得将增加输入称为已证实创新。

## 实测结果

| 场景：速度/负载 | 原 139 维 DQN，惩罚 4 | 加速率输入 DQN | 验证集选参的成本感知 PRS |
|---|---|---|---|
| 0.5 / 0.85 | 145.68 J / 0% | 151.65 J / 0% | 138.49 J / 0% |
| 2 / 1.00 | 161.86 J / 0.36% | 170.51 J / 0.24% | 138.67 J / 1.13% |
| 3 / 1.15 | 189.05 J / 8.57% | 196.85 J / 4.97% | 199.95 J / 1.96% |

高负载增加速率输入后，中断均值下降、能耗上升；不能称为同时改善
两个指标。新模型相对成本感知 PRS 少约 3.10 J（1.55%），但中断更高。

两训练种子 × 四轨迹的探索性交叉 bootstrap：

- 高负载 RL 中断率：4.97%，区间约 [1.85%, 9.61%]；上端超过 5%。
- RL 减成本感知 PRS 能耗差：−3.10 J，区间 [−32.36, 24.92] J，跨零。
- 中断率差：+3.01 个百分点，区间约 [+0.24, +7.05] 个百分点。

极小样本区间不能被当作严格统计认证。低负载观测 0% 中断的 bootstrap
也为 [0,0]，这不等于真实风险为零。

## 判断

1. 候选速率输入能够表达原状态缺少的用户间相关性；本轮说明它有
   降低高负载中断的开发迹象，但没有证明稳定的学习节能优势。
2. 低负载仍明显不如搜索，不能只挑高负载均值展示“RL 最好”。
3. 不能将 4.97% 四舍五入视为可靠地满足 5% 限制；下一步如果保留
   该方法，需要更多训练种子、新的验证/测试轨迹和可靠性余量。
4. 还要在更细或连续裕量调节的强搜索前沿上比较，避免搜索因粗网格
   过于保守，而 RL 刚好贴近约束所形成的不公平优势。
5. 原来的运行时间结论不适用于此新输入管线。正式保留前须重新测量。
