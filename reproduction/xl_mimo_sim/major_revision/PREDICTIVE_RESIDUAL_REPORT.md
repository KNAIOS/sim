# 预测基准上的三动作 RL：完成，但最终退回未学习的 PRS

## 结论先行

两个种子均完成 300 回合。按照事先确定的“先满足最差场景平均中断率，再
最小化能量”的验证规则，两者都选择第 0 回合，即完全不修正的 PRS。
因此没有建立学习收益，不能把开发集上较好的 PRS 数字记在 RL 名下。

## 实现和公平性

PRS 先给出计数，218 维输入的 Double DQN 只选择 −1、0、+1 修正。
零修正严格复现基线；初始贪心策略也是零修正，作为公开的退回候选。
计数边界在探索和两个 Q 网络中一致屏蔽。训练保留真实后继自举，价权为 4，
其余硬件、信道、功耗、观察限制、训练/验证/开发流均与计划一致。

每个种子保留第 0、50、100、150、200、250、300 回合检查点。
第 0 回合验证平均能量 158.335 J、最差场景中断率 3.988%；各后续检查点均未
在预设选择规则下超过它。没有根据开发结果重选模型。

本轮还评估了固定 −1、固定 +1、调定裕量的 PRS、含切换成本的 PRS，以及
此前的绝对计数 RL。保留简单修正规则，避免将任意加一/减一的效果归功于学习。

## 开发集结果

每个单元为平均回合能量（J）/ 用户–时隙中断率（%）。
三个场景各 16 条已查看轨迹；学习候选两个种子等权。

| 场景 | 选中的“残差 RL” | PRS | 固定减一 | 固定加一 |
|---|---:|---:|---:|---:|
| 0.5 m/s / 0.85 | 138.67 / 0.045 | 138.67 / 0.045 | 138.60 / 0.149 | 152.50 / 0.000 |
| 2 m/s / 1.00 | 142.80 / 2.664 | 142.80 / 2.664 | 140.42 / 4.464 | 155.96 / 1.042 |
| 3 m/s / 1.15 | 174.70 / 3.423 | 174.70 / 3.423 | 167.59 / 6.131 | 186.72 / 1.652 |

“残差 RL”与 PRS 相同不是巧合：96 条退回记录的能量、中断、分项能量、切换
次数和平均命令数均已逐项核对。相对含切换成本 PRS，高负载有约 0.056 J 的
均值差，区间跨零；这是两个搜索基线之间的差别，绝不是学习收益。审计脚本
已经明确区分原始均值差与可归因于学习的信号，后者为空。

固定减一的高负载能量低约 4.1%，但中断率 6.13% 超过 5%，不能当作可靠
节能。名义场景的平均中断率 4.46%，其开发重采样区间为约 [1.87%, 7.41%]，
仍不能宣称可靠性保证。固定加一改善平均中断率，却增加能量。

## 为什么此前的局部干预不能直接变成论文成果

单次加一有时能通过后续硬件/观察/控制变化节省能量，但“每次都加一”明显
多耗电。三动作学习又未在当前预算及目标下学出验证更好的选择。
局部事后机会、可学习性、独立测试优势是三个不同的证据层级；本轮只建立了
第一个层级及对当前候选的否定性筛查。

不能因此宣称 RL 在该问题上永远无用，也不能由此推出增加训练量必然有效。
目前可以说的是：这项固定价权、固定预算的局部修正假设没有通过筛查。
