# 新闭环与同风险对照：局部省电尚未成为学习优势

2026-09-21。执行前冻结ABSOLUTE_RETURN_SCREEN_PLAN；后续风险匹配检查
按另行声明的ABSOLUTE_RETURN_FRONTIER_PLAN进行，明确属于事后诊断。
**六个种子×场景晋级项全部失败，没有启动独立确认。**

## 1. 本轮完成了什么

没有继续训练上一轮失败的结构版，也没有放宽其门槛。只检验上轮free
消融中两个种子都出现的局部改善线索：保持100epoch终点、lambda=2及
原参考mu，在新106流三个场景各8条轨迹上持续闭环运行。

四种搜索各12配置重新校准：原PRS、原cost、使用精确当前CSI的current-PRS
与current-cost；另保留原mu和全阵列。新搜索仅替换当前首槽速率，真实
未来不可见，未来预测、硬件、物理模型不变。原PRS预测h=1..8，current
版本沿用cost的t..t+7时间轴，不能称为完全相同预测期的单点替换实验。

基线1200次、学习96次，共1296条完整回合记录；共享24条外生轨迹。
学习C4/C16来自同一共同训练的网络，比较的是决策时采用的成本长度，
不是两个独立训练长度。学习器没有本轮调参，而每种搜索校准12配置，
这项预算差异对学习器是保守筛查，不是等预算的全面算法排名。

## 2. 闭环结果：有一个能量下降点，但代价和边界必须同时看

能量为每7秒回合焦耳，不达标为用户时隙比例；下表学习值平均两个种子，
搜索和全阵列不复制成两个独立种子。最强搜索指验证中不达标<=5%的
最低能量纯配置，而不是全控制策略最优。

| 方法 | 低场景：J / 不达标 | 名义：J / 不达标 | 高场景：J / 不达标 |
|---|---:|---:|---:|
| C4学习决策 | 101.61 / 3.97% | 120.03 / 9.24% | 147.95 / 31.86% |
| C16学习决策 | 113.92 / 0.43% | 133.22 / 4.17% | 181.58 / 14.75% |
| 最强可行纯搜索 | 102.93 / 2.53% | 138.34 / 3.27% | 214.90 / 4.64% |
| current-cost | 102.93 / 2.53% | 138.49 / 3.24% | 215.18 / 4.67% |
| 全阵列 | 305.65 / 0.00% | 305.65 / 0.00% | 305.65 / 1.93% |

名义C16种子11为132.962J / 4.4345%，种子22为133.472J / 3.8988%；
相对cost的138.339J / 3.2738%，分别少耗3.89%和3.52%，但不达标增加
1.1607和0.6250个百分点，均超过预设0.5个百分点容差。虽然两均值低于
5%，也不能把未通过的原门槛写成通过。

名义同轨迹能量差分别-5.376±9.441J、-4.866±10.994J，±后是8条轨迹
配对差的样本标准差，不是置信区间；分别6/8、4/8条轨迹能量更低。
这不是独立确认：搜索配置在本集选择，且样本量小。

低场景C16多耗能以换取较低不达标；高场景省电却达14.75%不达标。
所以不能只保留名义平均能量，也不能把高场景的省电作为可靠节能。
把当前CSI交给搜索后，本样本的校准最优点变化不大，不说明它在所有
参数/信道下都不重要。

## 3. 为什么还检查简单混合搜索

纯搜索的裕量只能取离散网格。它可能落在3.27%不达标，而学习器落在
约4%，导致比较混合了“算法差异”和“使用多少可靠性余量”。
因此在已有数据上允许一个不学习的回合级混合：每回合开始前，按固定
概率选择搜索配置A或B，不看该回合未来。其期望指标由线性加权得到。
四搜索各12配置加全阵列共49点；枚举纯点和跨目标风险的二点组合。

| 名义场景 | 学习器能量 | 相同平均不达标下混合搜索期望能量 | 学习器减搜索 |
|---|---:|---:|---:|
| 种子11，目标4.4345% | 132.962J | 132.010J | +0.953J |
| 种子22，目标3.8988% | 133.472J | 133.972J | -0.500J |

两点均混合PRS(min=1,margin=1.04)与cost(min=4,margin=1.00)，选PRS
概率分别0.60870和0.47826。统一5%上限时，同一基线池的混合期望为
129.938J，选PRS概率0.74638。所有场景与种子共9组结果完整保留。

这说明原来的约3.5%--3.9%纯搜索能量差，并不能直接归为学习收益：
同风险比较缩小到不足1J且两个种子方向相反。**不宣称混合控制器已在
独立测试中击败RL**；配置与概率均由同一验证数据事后求出，报告的是
条件于这些样本的混合期望，不是随机执行实测或单回合安全保证。
这也不是全策略的最优下界，只是一个可实现的简单非学习对照类。

## 4. 对论文的影响

| 目标主张 | 新证据 | 仍缺什么 |
|---|---|---|
| 学习比强搜索更可靠节能 | 名义纯搜索差距伴随更多不达标；同风险差距不一致 | 跨种子、匹配风险的独立正面证据 |
| 后续成本能改善决策 | C16相对C4降低不达标但增加能量 | 不能称为同时改善两个指标或训练长度因果证明 |
| 精确成本分解是有效创新 | 本轮未继续失败结构版；上一轮消融不支持 | 不能借free结果回填结构版贡献 |

本轮没有新增可替换主稿的成功方法。下一轮若继续，必须针对“同风险
下边际动作价值如何估准”提出新可检验假设，不能再用单一搜索网格的
能量差作为成功，也不能继续扫描这个已停止候选的价格或种子。
当前R2/R3仍只证明原正式方法的敏感性和标准信道边界，不能自动移植。
