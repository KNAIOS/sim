# 长期价值重构完成：短时对照有所改善，但仍输给强搜索

2026-09-21。作者研发记录，不是可投稿的成功结论。
依据预先固定的 `BELLMAN_BRANCH_PLAN.md`、`BELLMAN_FIT_PLAN.md` 和
`BELLMAN_SCREEN_PLAN.md` 完成数据、两组训练及全部1800条闭环评估。
**两个主要筛查均失败，候选按协议停止，不启动独立确认或追加调参。**

## 1. 这次重构了什么

前一轮让网络预测“当前动作后，由一个冻结策略继续控制16个时隙”的
成本。这次不再使用该固定后续策略的长回放标签，而是记录真实的
“当前状态—动作—四时隙成本—下一状态”，逐轮更新后续价值。

第一步把确定的硬件能耗直接算出，不让网络近似它。第二步学习四时隙
通信不达标比例中未知的部分；当前时隙来自已经观测到的活动子阵CSI。
第三步冻结这个即时风险模型，再学习动作之后的长期能耗和通信损失。
部署选使预测“能耗+价格×不达标成本”最小的数量动作。

长时版本和短时消融共用完全相同的即时风险权重。长时版本多出的只有
后续价值，因此不能把另外训练一个较弱短时网络当作支持证据。
价格网格是0.5、1、2、4、8、16；各场景在验证集上选定价格，不依据
单条测试轨迹未来选价格。它不是数学上的5%可靠性保证。

这个原理属于已有fitted Q iteration及已知/未知成本分解，并非本研究
首创通用RL算法。文献依据及具体方程在三个预注册研发文件中；当前
结果也不足以把这项通信系统适配包装成已确认的新论文贡献。

## 2. 数据链和有界训练

- 三个原场景各4条新训练轨迹，共12条外生轨迹；种子11和22共享。
- 每种子分别沿冻结搜索和上一轮冻结学习器访问状态，保留全部35个
  决策时刻，每状态评价16动作。两种子共1680根状态、26880四槽转移，
  107520个分支物理时隙；重复的搜索数据不算额外独立样本。
- 每条训练轨迹额外生成真实第140时隙观测。计分仍为140槽；记录结束
  不被误记成终止，不会把后续成本偷偷设成零。部署输入无剩余回合时间。
- 新模型使用1500维因果状态及一个价格条件，16个数量动作，64387参数。
  即时风险网络100epoch；后续价值从第2至第16决策深度，每深度5epoch。
  最终预测范围是64物理时隙，不是“64步最优”或无限时域收敛保证。
- 两种子都从新初始化训练；未按验证选择训练终点。即时风险权重在
  后续拟合中保持不变；每轮目标网络冻结，最终严格重载预测完全相同。

计数、动作域、需求、信道、恢复时延、功率和开关/导频开销均未调整。
当前动作的解析能耗与仿真转移最大归一化误差小于2.97e-8，已知当前
不达标比例误差小于1.99e-8；所选分支与实际滚动轨迹成本完全一致，
下一状态逐元素一致。未来信息隔离和真实截断后继测试均通过。

## 3. 全部闭环结果

新验证流111，三个场景各8条轨迹，共24条。学习版本含两种子、两深度、
六价格，以及冻结旧学习器，共624条记录。四类搜索各12配置加全阵列，
共1176条记录。全部保留，总数1800，不是1800条独立外生轨迹。

搜索比每个学习版本获得更多调参配置；这是偏保守的研发筛查，而非
等调参预算的所有算法排名。价格先按5%可行性、再按能量选定，不以
是否“能赢搜索”选点。无可行价格时，展示最低不达标者并明确失败。

下面每格为“整段能量J / 用户时隙不达标比例”；每条回合7秒。

| 方法 | 低场景 | 名义场景 | 高场景 |
|---|---:|---:|---:|
| 长时RL，种子11 | 107.15 / 4.70% | 141.29 / 2.38% | 204.07 / 6.64% |
| 长时RL，种子22 | 122.20 / 1.22% | 133.44 / 4.29% | 193.77 / 11.43% |
| 共用风险的短时对照，种子11 | 111.57 / 2.08% | 123.13 / 4.64% | 168.92 / 14.20% |
| 共用风险的短时对照，种子22 | 104.59 / 3.39% | 135.18 / 4.05% | 172.40 / 14.38% |
| 冻结前一轮mix_pi，种子11 | 115.09 / 1.43% | 128.70 / 4.94% | 175.40 / 13.33% |
| 冻结前一轮mix_pi，种子22 | 111.88 / 1.10% | 130.56 / 3.66% | 163.42 / 14.38% |
| 最低能耗的可行纯搜索 | 103.28 / 3.90% | 122.40 / 4.85% | 202.00 / 4.02% |

高场景两个长时模型的六个价格均不能达到5%平均目标。其最优展示价格
均为16；没有据此继续扩大价格网格。种子22比纯搜索的较低能量伴随
明显更高不达标，不能称为有效可靠节能。

原先mix_pi的1.63%/1.11%来自109流，不能与本表绝对值直接相减。
本次在111流上也实际重跑了冻结旧学习器，表中提供的是同轨迹对照。

## 4. 相同可靠性下，仍没有比强搜索更节能

在49个搜索/全阵列点上枚举回合级两策略混合，使其平均不达标不高于
所比较学习器。以下是验证拟合的期望，不是重新实测的随机混合部署，
也不是全部可实现控制器的最优下界。

| 场景/种子 | 长时RL能量 | 同风险搜索期望能量 | RL多耗能量 | 配对差样本SD | 8条中RL能量更低 |
|---|---:|---:|---:|---:|---:|
| 低/11 | 107.15J | 102.98J | +4.17J | 3.75J | 1 |
| 低/22 | 122.20J | 109.87J | +12.33J | 9.38J | 1 |
| 名义/11 | 141.29J | 127.35J | +13.94J | 13.05J | 1 |
| 名义/22 | 133.44J | 123.51J | +9.93J | 16.11J | 3 |
| 高/11 | 204.07J | 190.93J | +13.14J | 18.98J | 2 |
| 高/22 | 193.77J | 170.69J | +23.08J | 29.16J | 2 |

高场景的配平仅用于诊断，其风险本身仍不可行。名义场景不是“稍低于
预设2%节能门槛”，而是两个种子均比同风险搜索多耗能；所以这轮失败
不能归结为门槛定得太高。SD是配对轨迹差的离散程度，不是均值置信区间。
没有把重复动作分支当独立样本计算显著性，也没有缩短误差棒。

名义场景的长时模型确实低于六个短时价格加全阵列构成的同风险混合
能量：种子11为141.29对188.05J，种子22为133.44对134.42J。这只支持
**在当前有限模型/价格集合中，长时控制相对该短时对照有改善**。
它不能证明比所有短时控制都好，更不能替代与更强预测搜索的比较。
低场景两个种子甚至没有优于短时同风险边界。

## 5. 本轮结论和停止边界

| 想支撑的主张 | 实际证据 | 结论 |
|---|---|---|
| 真实四槽转移及后继可以正确供RL学习 | 全动作核查、回放、因果性、截断处理、严格重载 | 实现检查通过，不等于控制成功 |
| 长期价值对节能有用 | 名义同风险优于共用风险的有限短时对照 | 有局部支持，不能推广全部负载 |
| 比强搜索更节能且可靠 | 六个场景/种子同风险差均不利，高场景超5% | 未建立，R1仍未解决 |
| 能沿用原R2/R3作为新模型证据 | 原主稿是另一套72输入模型 | 不能移植；当前不改主稿 |

按冻结方案停止该候选，不增加深度、价格、训练种子或训练终点，不把
失败的样本重新命名成确认集。若继续新的研究，应先针对预测/价值误差
提出可证伪的诊断，而不是把更大网络或更多训练默认当作答案。本报告
不声称已查明唯一失败原因，也不推断任何RL都不可能优于搜索。
