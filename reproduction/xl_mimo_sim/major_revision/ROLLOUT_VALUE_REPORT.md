## 1. 这次实际改了什么

不再用旧DQN的单步自举目标，也不把搜索动作本身当分类标签。对同一因果
状态，分别尝试1--16个子阵的根动作一次，然后返回同一个强搜索规则，
用仿真产生后续成本。分支共享外生信道，但各自保留硬件、观测和跟踪历史。

保存两种价值：C4只计算根动作的四时隙；C16计算根动作及后续三次搜索
控制，共16时隙，按每四时隙0.98折扣。每种价值都分为能量和用户时隙
不达标两个分量，学习相对参考搜索根动作的成本差，而非精确长期Q。
这是近似策略评价/改进候选，通用rollout思想并非本文创新；理论来源及
部分观测、截断、函数近似限制已写在计划中，不引用精确改进保证。

输入1436维：原1434维因果通信/硬件/动作特征，另加参考搜索的需求裕量
和最小计数配置。共享网络含32066参数，每动作两个输出；用同一网络输出
相减保证参考动作成本差严格为零。它不输入未来信道、轨迹编号或回合尾部
信息。线上仍要计算搜索与动作特征，因此不能沿用旧72维模型的计时。

训练数据为新101流72条轨迹、576个根状态、9216个分支；验证为新102流
36条轨迹、288个根状态、4608个分支。每个状态只有一条样本未来，不是
条件期望的高精度Monte Carlo估计。两种子×两种回放长度各100个epoch，
总400个epoch，固定最终端点，没有按验证损失挑epoch。

## 2. 预测门槛通过，但它只是中间检查

在参考搜索产生的验证状态上，C16相对于“所有动作成本差都预测成零”的
误差比例如下。小于0.9是预先规定的拟合门槛，不是性能保证。

| 种子 | 能量差MSE / 恒零MSE | 不达标差MSE / 恒零MSE | 结果 |
|---|---:|---:|---|
| 11 | 0.1284 | 0.5353 | 通过拟合门槛 |
| 22 | 0.1150 | 0.5212 | 通过拟合门槛 |

参考附近正负一个子阵动作的能量误差改善小得多：C16两种子的MSE为
0.004319 / 0.004147，恒零为0.005602。这说明全动作平均误差不能替代
决策相关的精度。也不能跨C4/C16直接比较原始MSE并声称一个更准，因为
两者预测的累计目标不同。

## 3. 完整闭环比较：没有达到可靠节能目标

同一102验证集上，重新校准prs/cost各12组设置，共864次评估；加原参考
搜索mu和全阵列72次，共936条基线记录。C4/C16两种子各五个价格、三个
场景，共720条学习候选记录。价格仅取1/2/4/8/16，按场景验证可行性优先、
再最低能量选择；所有价格及不利结果均保留。

下表均为每条7秒回合平均能量J / 用户时隙不达标率。学习项平均两个种子，
搜索/全阵列不重复算作两个独立种子。每场景只有12条外生轨迹；它们已被
用于价格选择和拟合诊断，因此这些不是独立确认成绩或可靠性置信保证。

| 方法 | 低场景 | 名义场景 | 高场景 |
|---|---:|---:|---:|
| C4局部价值学习 | 106.12 / 2.66% | 151.63 / 4.08% | 201.38 / 13.32% |
| C16后续价值学习 | 114.02 / 1.36% | 145.95 / 4.85% | 219.74 / 11.42% |
| PRS | 102.25 / 4.84% | 136.46 / 3.12% | 208.15 / 4.74% |
| 切换成本搜索 | 102.21 / 4.96% | 136.67 / 3.21% | 208.07 / 4.80% |
| 原参考mu | 102.21 / 4.96% | 136.67 / 3.21% | 208.07 / 4.80% |
| 全阵列 | 305.65 / 0.00% | 305.65 / 0.00% | 305.65 / 2.46% |

本次重新校准碰巧仍选中原mu的参数；不是省略了重新校准。场景同时改变
速度和需求倍率，不是两个变量各自独立的因果实验。

C16种子11/22分别为：

| 场景 | 价格11/22 | 种子11能量 / 不达标 | 种子22能量 / 不达标 |
|---|---|---:|---:|
| 低 | 1 / 1 | 115.86 / 1.49% | 112.17 / 1.23% |
| 名义 | 2 / 8 | 140.10 / 4.94% | 151.80 / 4.76% |
| 高 | 16 / 16 | 218.84 / 12.06% | 220.64 / 10.77% |

六个种子×场景晋级项全部失败。名义场景C16平均比最强可行搜索多耗约
9.49J（6.95%），且不达标更高；高场景不仅不达标超过5%，能量也更高。
低场景是花更多能量降低不达标，不是同一约束下的节能优势。不能只保留
种子11相对C4的能量下降，而隐去强搜索或种子22。

## 4. 为什么拟合通过仍未转化为优势

闭环失败后，对已保存的参考搜索验证根状态做一次事后动作排序核查。
使用已锁定的价格和网络，不修改模型。这里的数值是四决策块累计的
归一化能量差加价格乘不达标差，负数代表比参考动作更低成本，不是J或百分比。

| C16种子 / 场景 | 预测平均成本差 | 对应样本未来的真实平均成本差 | 改动作次数 | 其中预测好、样本却更差 |
|---|---:|---:|---:|---:|
| 11 / 低 | -0.0603 | +0.0366 | 46/96 | 37/46 |
| 22 / 低 | -0.0671 | +0.0469 | 48/96 | 41/48 |
| 11 / 名义 | -0.1160 | -0.0150 | 66/96 | 32/66 |
| 22 / 名义 | -0.6654 | -0.1995 | 74/96 | 43/74 |
| 11 / 高 | -1.0124 | +0.6095 | 66/96 | 48/66 |
| 22 / 高 | -0.9087 | +0.6215 | 71/96 | 47/71 |

误判在原参考策略的状态上已经出现，因此不能只用“新策略运行后状态分布
变了”解释失败。名义场景的加权样本成本虽改善，但两个种子实际能量分量
均增加，只是通信损失下降；这也不能称为节能改善。

每根状态只有一条真实样本未来。样本上“更差”不能证明该动作的条件期望
一定更差，表格不是Q统计偏差的定理，也不是对全部运行状态的校准证明。
它提示后续若再重构，应先解决被选动作的风险/收益估计可信度，而不是
继续以全动作平均MSE下降作为成功依据。本轮不因此追加训练或改筛查阈值。

## 5. 证据完整性与已修复的问题

- 原始标签参考动作回放误差最大5.89×10⁻¹⁵（归一化成本）；参考差严格为零。
- 数据、模型和源文件哈希核验通过；四个最终模型都严格加载并重算预测。
- 936+720条闭环记录主键唯一，逐条选模重算一致；能量分项误差最大
  5.29×10⁻¹⁴J。原始记录、两种子及所有价格未删减。
- 第一版汇总将不同字段的学习/基线记录写入同一CSV时失败。只修复报告
  字段并集序列化，没有改数据、训练、选模或门槛；增加回归测试。原不完整
  `closed_audit/`和失败源码快照保留，正确且完整版本为`closed_audit_v2/`。
- `decision_audit/`有1152行事后核查，但只有288个基础验证根状态，不据此
  增大独立样本数。没有做显著性优越性宣称。
- 本轮仿真、拟合和闭环作业都正常退出；只用原项目venv，没有安装依赖、
  修改主机或服务器环境。正式黄色版与清稿PDF哈希未变。
- 最终完整回归为111项通过（90项返修模块、21项原模块）；测试和源码哈希
  证明的是实现/复现范围，不代表科学主张或录用条件已经成立。
