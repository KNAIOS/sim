# 速率裕量公平对照：开发筛查，2026-09-20

## 已完成内容

新增 `margin_frontier.py`，保持真实负载、信道、功耗与评价公式不变，
仅在搜索决策中调整预测速率需求裕量。原 `future_vr` 未修改。
新增单测确认裕量不修改实际业务需求；5 项新增测试和 21 项旧回归测试通过。
仅使用本地既有包内 venv，本轮没有安装依赖或修改服务器环境。

验证集：每场景 4 条轨迹，种子流 924000000+j*10000+i；
独立开发评估集：每场景 4 条轨迹，925000000+j*10000+i。
这仍是开发筛查，不是最终测试，也没有统计可靠性保证。

PRS 与成本感知 PRS 各扫描 1/1.05/1.10/1.20/1.35/1.50 六个裕量。
每个场景分别用验证集选择：在平均中断率不超过 5% 的选项中取最低能耗。
没有用开发结果反选裕量。两种 DQN 均使用上一轮两个种子的冻结模型。
允许搜索按场景选参数，对其较有利；并非两方法完全相同的部署配置。

验证 144 条、开发评估 72 条。首次启动因 NumPy 检查点元数据的受限
加载失败，原失败目录保留；修正为仅允许特定 scalar/dtype 类型，
仍使用 weights_only=True；完整成功运行在 `_v2` 目录。

## 独立开发结果

数值为 episode 能耗 / 平均速率中断率。

| 速度 / 负载倍数 | 裕量 PRS | 成本感知裕量 PRS | 原 DQN | 增强输入 DQN |
|---|---|---|---|---|
| 0.5 / 0.85 | 138.51 J / 0% | 138.51 J / 0% | 171.19 J / 0% | 158.66 J / 0% |
| 2 / 1.00 | 141.59 J / 2.50% | 141.49 J / 2.50% | 199.02 J / 0.36% | 198.78 J / 1.49% |
| 3 / 1.15 | 171.72 J / 3.10% | 171.75 J / 3.04% | 214.64 J / 2.08% | 201.64 J / 1.73% |

两种搜索均在低/名义场景选择 1.00、高负载选择 1.05。
高负载增强 DQN 比裕量 PRS 多消耗约 17.4% 能量，但其中断率更低。
不能据此断言搜索在精确同等中断率处必然更优；同样不能声称 RL 是
满足 5% 门槛时已发现的最低能耗方案。极小样本均值不等于约束保证。

## 对下一步的影响

1. 高负载下原 PRS 不满足门槛，并不能建立 RL 独有优势；简单裕量已能
   在本轮开发均值上修复它。不能省略这个强对照。
2. 不直接启动大量同配方训练。先检查可选动作的预测速率、用户间干扰
   和可靠性代价是否足以支持 DQN 的节能决策；额外计算也必须计入复杂度。
3. 下一轮应扫描 RL 的可靠性代价并验证能耗—中断率前沿，不能只比较
   一个过于保守的 RL 点。新算法必须明确区别于调大/调小奖励权重。
4. 标准信道接入尚未完成；参见 STANDARD_CHANNEL_PLAN.md，不能把查阅
   官方实现文档当成完成标准验证。
5. 暂不把本次小样本数值写成论文最终结论，不覆盖原稿或原有不利结果。
